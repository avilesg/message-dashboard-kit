# 07 — Back up personal config

```
Write or update config/personal.json from what you remember about my setup (group label and JID, timezone, store path, priority people, keywords, custom topics, alert settings), using config/personal.example.json as the shape. Keep it gitignored and never commit it to the public kit. Then give me a downloadable copy named personal-config-backup-YYYY-MM-DD.json and tell me what changed since the last backup. Do not change the send lock: wacli stays read-only.
```

Repeat after any change to people, keywords, or alerts. See `config/BACKUP.md`.
