Message dashboard: capability overview (Zoom workshop)
======================================================

Files
  capability-overview.html          8-slide deck: the components that make up the Message dashboard capability
  message-dashboard-architecture.jpg  architecture graphic used on slide 4 (keep it next to the .html)
  renders/                          preview screenshots — not in this repo (not needed to present)

Suggested workshop order
  1. capability-overview.html            (this folder)            what you're building, ~5 min
  2. ../startup-options/startup-options.html                      how to start: A / B / C
  3. ../startup-options/key-prompts-handout.html                  leave-behind with the setup prompts
  Tutorial Page: paste the link in the Zoom chat.
  The multi-AI intro deck (intro-landing-slides.html) is optional, only if you choose that arc
  as a separate session.

Slides
  1 Title: your group chat -> your own private dashboard
  2 Principle: your copy on your bot's computer; only the recipe (kit + optional template) is shared
  3 Components map: WhatsApp, wacli, store, ontology/topics, classifier + scripts,
    Message tracker Page, optional alerts, kit repo + bot template, personal.json backup
  4 Architecture graphic
  5 Data flow: phone -> wacli -> store -> classify -> tracker (+ optional alerts)
  6 Shared vs private
  7 Where each workshop piece fits (overview, startup options, handout, tutorial Page)
  8 Safety: send lock; don't republish group content

Presenting
  - Open in Chrome/Edge, press F for fullscreen, share that tab or window in Zoom.
  - Next: Right arrow / Space / Enter / click.  Back: Left arrow / Backspace / right-click.
  - Home / End jump to first / last slide. Adding #5 to the URL opens slide 5.
  - Print/PDF: Ctrl+P, landscape, "Background graphics" on.
