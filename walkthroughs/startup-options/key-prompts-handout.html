Six prompts from WhatsApp to a Message tracker

The prompts I used to get a dashboard of my messages by topic. Paste them in order into your Grok Bot chat.

CAPS = fill in your own Kit: github.com/avilesg/message-dashboard-kit

Imported the Message Dashboard template (Option B)? Its getting-started skill runs most of these steps for you (the ones tagged template runs this). Keep this sheet anyway, as a handout and a recovery checklist if a step fails or you set up a new bot.

  1. Load the kit template runs this

    Use https://github.com/avilesg/message-dashboard-kit as your starting point. Read README.md, docs/TUTORIAL.md, ontology/, scripts/, and prompts/. Don't fork or push anything. Keep my group ID, name, and any people lists in your memory only — never in a repo.

    Gives the bot the recipe. Your personal details stay in its memory.

  2. Install wacli template runs this

    Install wacli (https://wacli.sh) on your box computer, with its store in a private folder. Don't pair yet — tell me when you're ready to show a QR code.

    wacli is the WhatsApp linked-device tool the bot reads your messages through.

  3. Pair with WhatsApp template runs this

    Show me the wacli pairing QR. I'll scan it from WhatsApp > Settings > Linked devices > Link a device. After pairing, run a full history sync, then list my groups so I can pick MY GROUP NAME. Remember its JID.

    Have your phone ready. The QR code expires quickly, so ask again if it does.

  4. Send lock template runs this

    Lock wacli to read-only: never send, react, type, or mark-read in any chat. Add a guard so any send command fails, and confirm the lock to me.

    A safety step: the bot can read, but it can never post as you.

  5. Build the tracker the dashboard of messages by topic template runs this

    Using the kit's scripts (classify_store.py, build_roster.py, build_messages_embed.py) and ontology/topics.share.json, build me a "Message tracker" Page for my group: Global and Custom tabs, a Phone roster tab, facet filters (topic, author, date, media), and threads grouped by topic, collapsed by default with counts. Keep outputs on your computer only.

    This is the payoff: your group's threads sorted by topic, with filters.

  6. Alerts optional template asks

    Optional: start from examples/notification_config.example.json and set up alerts for me — critical (instant), daily digest, weekly digest — sent only to my chat with you. Ask me for keywords and people to watch; keep them in your memory, not the repo.

    Alerts go only to your chat with the bot. Your keywords and names stay out of the repo.

  7. Back up your settings repeat after changes

    Write or update config/personal.json from what you remember about my setup (group label and JID, timezone, store path, priority people, keywords, custom topics, relationship/topic weights if any, alert and digest settings, notification config pointers). Preferences and config only: do NOT include WhatsApp messages, message store data, or media., using config/personal.example.json as the shape. Keep it gitignored and never commit it to the public kit. Then give me a downloadable copy named personal-config-backup-YYYY-MM-DD.json and tell me what changed since the last backup. Do not change the send lock: wacli stays read-only.

    If the bot computer is reset, upload this file to a new bot to restore your prefs. It holds settings only, not messages (a message-store backup is a separate, optional job). Keep it private (Drive or an encrypted note).
