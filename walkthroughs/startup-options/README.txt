Startup options + key prompts — how to present
==============================================

Files (self-contained, no internet needed except the links inside):
  startup-options.html      7-slide add-on deck: three ways to start a Message dashboard bot
  key-prompts-handout.html  printable one-pager: the 6 setup prompts, numbered
  renders/                  preview screenshots and a print test PDF — not in this repo (you don't need these to present)

Suggested Zoom flow
  1. Present capability-overview.html first (the components you're building; see its own folder).
  2. Switch to startup-options.html for the "how do I get one" part (about 5 min).
  3. Share key-prompts-handout.html as the leave-behind (send the file or a PDF of it).

startup-options.html (deck)
  - Open in Chrome/Edge, press F for fullscreen, then share that tab or window in Zoom.
  - Next: Right arrow / Space / Enter / click.  Back: Left arrow / Backspace / right-click.
  - Home / End jump to the first or last slide. Adding #3 to the URL opens slide 3.
  - Slides: 1 Title · 2 Option A (new bot + git kit) · 3 Option B (import template, fastest)
            4 Option C (fork/clone, personal.json gitignored) · 5 A vs B vs C table
            6 Reminder: you own the archive + dashboard; only the recipe is shared; back up personal.json
            7 What you can configure (new): 10-card grid of every setting (group & store, priority
              people, keywords/buy-box, notify levels + quiet hours, ontology layers, ontology review
              [new: bot chat flags core-git topics vs candidates from new messages; you agree or tweak
              first], ontology freshness via ontology/LAST_UPDATE, prefs backup, safety/send lock,
              optional Slack/email). Open slide 7 directly with #7. Preview PNGs are not in this repo.
  - Talking point: for a live Zoom, recommend B (template). A and C are for people who want
    transparency or full control.
  - Print/PDF: Ctrl+P, landscape, "Background graphics" on, prints one slide per page.

key-prompts-handout.html (handout)
  - A scrollable page in large type. Zoom in the browser (Ctrl +) if people can't read it on screen.
  - Each prompt has a Copy button (hidden when printed). Yellow CAPS = fill in your own.
  - Print/PDF: Ctrl+P, portrait, turn on "Background graphics" so the colors print. About 3 Letter pages.
  - Template note at the top: the getting-started skill runs most steps, so this page is also a
    recovery checklist.
