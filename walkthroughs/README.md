# Walkthrough HTML (Zoom)

Self-contained HTML decks used in the Message dashboard walkthrough. Open each `.html` file in a browser (arrow keys / click to advance). Prefer **git / repo** wording when you edit these.

| Folder | Open | Purpose |
|--------|------|---------|
| `intro-landing/` | `intro-landing-slides.html` | Intro landing (meaning / knowledge / multi-AI framing) |
| `capability-overview/` | `capability-overview.html` | High-level capability components + architecture graphic |
| `startup-options/` | `startup-options.html` | How to start a bot (template vs git vs from scratch) + **What you can configure** |
| `startup-options/` | `key-prompts-handout.html` | Key prompts handout (chat → topic dashboard) |

Architecture JPGs sit beside the HTML that references them. PNG slide renders are optional and not committed.

**Privacy:** these decks must not include private WhatsApp messages, JIDs, or personal notify lists. Keep ownership / chat-history ownership materials separate from multi-AI slides when you edit.
